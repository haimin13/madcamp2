# 🎮 CoRope: 협동 탈출 대작전

> **"줄로 연결된 두 캐릭터, 완벽한 협동으로 탈출하라!"**  
> Ninja Frog와 Virtual Guy가 함께 사과 3개를 먹고 탈출하는 **2인 협동 2D 플랫포머 게임**!

---

## 📌 프로젝트 소개

**CoRope**는 줄로 연결된 두 플레이어가 **사과를 수집하고 탈출 지점에 도달**해야 클리어할 수 있는 **Unity 기반 2D 횡스크롤 협동 게임**입니다.

- **개발 플랫폼**: Unity 6.1
- **사용 기술**:  
  - Unity WebGL
  - OAuth 2.0 (Google Login)
  - Maria DB
  - 
- **주요 기능**:
  - 🪢 줄로 연결된 캐릭터 협동 이동
  - 🍎 사과 3개 수집 시 탈출 가능
  - 🕹️ 키보드 2인용 조작 (W/A/S/D & 방향키)
  - 🕒 타이머 및 게임 기록 서버 전송
  - 🌐 WebGL 배포

---

## 🎮 게임 플레이 방식

1. 플레이어 1 (Ninja Frog)과 플레이어 2 (Virtual Guy)를 조작하여 이동
2. 줄에 제약을 받으며 사과를 3개 모두 수집
3. 함께 도착지점으로 이동하면 클리어!
4. 기록은 자동으로 서버에 저장되어 랭킹화 가능

## ⚙️ 조작 방법

| Action       | Player 1 | Player 2 |
|--------------|----------|----------|
| Move Left    |    A     |    ←    |
| Move Right   |    D     |    →    |
| Jump         |    W     |    ↑    |
| Hold Down    |    S     |    ↓    |
| Restart      |    R     |    -    |
| Map Select   |   ESC    |    -    |
